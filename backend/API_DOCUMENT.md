# Totsuko Motors Backend API Document

Base URL: `http://localhost:3000`

Authentication uses HTTP-only cookies:
- `token`: access token, set by login/register/refresh.
- `refreshToken`: refresh token, set by login/register.

| Method | Endpoint name | Purpose | Example request body | Example response body |
| --- | --- | --- | --- | --- |
| `GET` | `/api/health` | Check whether the backend API is running. | No body | <pre><code>{&#10;  "status": "ok",&#10;  "message": "Totsuko Motors API is running!"&#10;}</code></pre> |
| `POST` | `/api/auth/login` | Log in with email or username and password. Sets `token` and `refreshToken` cookies. | <pre><code>{&#10;  "emailOrUsername": "clerk01",&#10;  "password": "password123"&#10;}</code></pre> | <pre><code>{&#10;  "success": true,&#10;  "message": "Login success",&#10;  "user": {&#10;    "userId": "U123456789",&#10;    "employeeId": "C123456789",&#10;    "name": "Somchai Clerk",&#10;    "email": "somchai@example.com",&#10;    "username": "clerk01",&#10;    "phone": "0812345678",&#10;    "role": "clerk",&#10;    "hireDate": "2026-04-28"&#10;  }&#10;}</code></pre> |
| `POST` | `/api/auth/register` | Register an employee user. Valid roles are `technician`, `clerk`, and `purchasingStaff`. Sets `token` and `refreshToken` cookies. | <pre><code>{&#10;  "email": "tech01@example.com",&#10;  "username": "tech01",&#10;  "password": "password123",&#10;  "role": "technician",&#10;  "name": "Suda Technician",&#10;  "phone": "0899999999",&#10;  "hireDate": "2026-04-28"&#10;}</code></pre> | <pre><code>{&#10;  "success": true,&#10;  "message": "Register success",&#10;  "user": {&#10;    "userId": "U987654321",&#10;    "employeeId": "T987654321",&#10;    "name": "Suda Technician",&#10;    "email": "tech01@example.com",&#10;    "username": "tech01",&#10;    "phone": "0899999999",&#10;    "role": "technician",&#10;    "hireDate": "2026-04-28"&#10;  }&#10;}</code></pre> |
| `POST` | `/api/auth/logout` | Log out the current user and clear auth cookies. | No body | <pre><code>{&#10;  "success": true,&#10;  "message": "Logout success"&#10;}</code></pre> |
| `GET` | `/api/auth/verify` | Verify the current `token` cookie and return the authenticated user profile. | `GET` | `/api/service/service-request?page=1&limit=10&status=Pending` | Get paginated service requests for the clerk dashboard. `page`, `limit`, and `status` are query parameters; `status` is optional. | No body | <pre><code>{&#10;  "success": true,&#10;  "data": [&#10;    {&#10;      "requestId": "RABC12345",&#10;      "checkingDate": "2026-04-28T12:00:00.000Z",&#10;      "requestStatus": "Pending",&#10;      "problemDescription": "Engine noise",&#10;      "odometer": 85000,&#10;      "customerName": "Anan Customer",&#10;      "plateNumber": "ABC-1234",&#10;      "clerkName": "Somchai Clerk"&#10;    }&#10;  ],&#10;  "meta": {&#10;    "currentPage": 1,&#10;    "itemsPerPage": 10,&#10;    "totalItems": 1,&#10;    "totalPages": 1,&#10;    "hasNextPage": false,&#10;    "hasPrevPage": false&#10;  }&#10;}</code></pre> |
